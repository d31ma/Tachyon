Build all platforms

Use all for release validation, then preview one target at a time. Non-web bundles always render native controls first and preserve a bounded fallback boundary for unsupported subtrees. Embedding is platform-specific; Windows currently uses an external placeholder. 

ty bundle --target all
ty bundle --target android
ty preview --target web
