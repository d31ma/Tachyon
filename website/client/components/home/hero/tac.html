Ship the whole stack faster than light.

Tachyon is a polyglot, file-system-routed full-stack framework whose core CLI ships as the standalone ty binary; selected companion languages and native targets still use their platform toolchains. Tac renders reactive pages and components; Yon serves routes written in JavaScript, TypeScript, Python and any executable that speaks the handler protocol; supervised workers, middleware and durable SSE topic logs use the same runtime. The same strict HTML becomes browser DOM, SwiftUI on Apple platforms, android.widget views on Android, Win32 common controls on Windows, or GTK4 controls on Linux — no platform-specific view language required.
