One convention, every layer

Templates, polyglot companions and backend routes all follow the same file-beside-file shape.

Tac template

client/pages/tac.html — interpolation, events, control flow and client-owned rendering in plain HTML.

Companion

client/components/hero/tac.js — a plain class with an explicit browser mount hook.

Yon route

server/routes/posts/yon.js — verbs are static methods; return plain data.

Polyglot companion

client/components/counter/tac.swift — a portable reactive controller beside its template.
