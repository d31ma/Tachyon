Yon backend

Filesystem routes, polyglot handlers, production guardrails.

Yon is Tachyon's server runtime. Drop yon.<ext> files under server/routes, declare an @Controller class, and Tachyon wires HTTP methods, bounded process supervision, middleware and request identifiers around each request. 

ty init api --name "My API"
cd api
mkdir -p server/routes/health
ty serve

ty serve detects whether the app has client/, server/, or both, then serves the right runtime on one port.

ty serve
YON_PORT=8000 ty serve
NODE_ENV=production ty serve

Handlers return protocol responses. Yon binds route parameters, supervises the process, preserves headers and bodies, and reports bounded failures consistently.

@Controller, @Service, @Repository, @Client and @Delegate must match their directory and class suffix. Missing declarations fail with TY2015.

server/routes/items/yon.py
server/services/catalog.py
server/delegates/report.py

Handlers append NDJSON records to bounded topic logs; browsers subscribe with EventSource and resume from the last event position.

new EventSource('/.tachyon/topics/releases')

Middleware uses a Yon language. Existing programs in other languages stay behind a supervised @Delegate method carrying @Relay.

@Delegate
class ReportDelegate:
  @staticmethod
  @Relay("ruby", "server/delegates/report.rb")
  def generate(request):
    raise RuntimeError("proxy body is never called")

Yon serves loopback by default with security headers, rejects path traversal, bounds bodies and handler time, and emits stable diagnostics when a process fails.

ty serve
ty doctor
ty migrate check

Owned Yon runtimes

Yon owns eight route runtimes. @Stream supports direct multi-frame SSE in JavaScript, TypeScript, Python, PHP, Kotlin and C#; Java and Rust return one response. Runtime overrides use YON_JAVASCRIPT_RUNTIME and YON_PYTHON_RUNTIME.
