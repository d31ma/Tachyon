Which languages a socket is written in

  .js, .ts   a @SocketRoute class; the session has openSessions()
  .py        a @socket_route class; the session has open_sessions()
  .go        a // @SocketRoute type; the session has OpenSessions(), Request()
  .java      a @SocketRoute class; the session has getOpenSessions()
  .kt        a @SocketRoute class; the session has openSessions()
  .cs        a [SocketRoute] class; the session has OpenSessions()
  .fs        a [<SocketRoute>] type; the session has OpenSessions()
  .php       a #[SocketRoute] class; the session has openSessions()
  .rb        a #[SocketRoute] class; the session has open_sessions
  .lua       a -- @SocketRoute class table; the session has open_sessions()
  .rs        a #[SocketRoute] struct; the session has open_sessions()
  .dart      a @SocketRoute class; the session has openSessions()

Every Yon language holds a socket. Tachyon keeps one handler
process running for the whole connection, and the runner or
prelude of each language reads the socket's message frames while
the class runs. Each language names the session methods in its
own style (above). In Go, session.Request() returns the request
that opened the socket as an *http.Request, with the query string
and the headers. A method that throws, panics or returns an
error counts as a failure. In Rust the object is shared, so its
fields keep state in a Cell or a lock.

When OnOpen or OnMessage fails, OnError runs and the socket stays
open, as in Jakarta. The error text goes to the server log only.

In the browser, @SocketRequest is JavaScript, TypeScript, Go or Swift.
Every Tac language receives the messages with @OnEvent. A Go
client is an interface method; the page holds the socket for the
Go service that keeps the client in a // @Needs field, and the
generated Send(message any) error returns HTTP_NETWORK when 16
messages already wait for the socket to open. A Swift client is a
protocol method, and its generated send(_ message:) async throws
throws the same codes.

Limits: messages are JSON text of at most 64 KiB, at most 32
sockets are open at once, five idle minutes or one hour close a
socket, and only pages from the same origin may open it. A
socket path has no {variables}; send the value in a message.

What the browser gets when a rule is broken:

  403   the page comes from another origin
  426   a plain HTTP request asks for the socket path
  503   32 sockets are already open; try again later
  1007  the message is not JSON, or does not fit the model
  1003  the message is binary data, not JSON text
  1009  the message is larger than 64 KiB
  1001  the socket was idle for five minutes, the browser went
        away, or the server is stopping

The route list in /api.json and the OPTIONS answer of the path
mark a socket with "socket": true. When a socket closes with
another code, the browser client opens it again after 1, 2, 4, 8
and 16 seconds. It does not open it again after 1000, 1003, 1007
or 1009. While the socket is not open, send(message) keeps at
most 16 messages and sends them when the socket opens.
