Which languages a stream is written in

  .js, .ts   an async generator
  .py        a generator
  .php       a generator, framed by the prelude
  .kt        a Sequence, framed by the prelude
  .cs        an IEnumerable or IAsyncEnumerable, framed
             by the prelude
  .fs        a seq or IAsyncEnumerable, framed by the prelude
  .dart      an async* Stream, framed by the prelude
  .rb        a method that yields, framed by the runner
  .lua       a method that calls coroutine.yield, framed by
             the runner
  .go        an iter.Seq or iter.Seq2 iterator, framed by
             the prelude
  .rs        an impl Iterator, framed by the prelude

Every Yon language with a generator streams. A stream is a route method that answers more
than once, and native generator syntax produces it.
Each language adapter or protocol prelude keeps that generator open
and emits one bounded frame per value.

Java and Groovy are deliberately single-response because
neither has a native generator. Tachyon refuses StreamRoute on
them (TY2015). A streaming route can use any generator-capable Yon
language.

In one controller, either every GET route is a StreamRoute or none is.

A Go stream that can fail returns iter.Seq2[Model, error]; the
first error ends the stream, and the browser gets event: error
without the error text. A stream has the request
time limit: at the limit the server stops it and sends
event: error, and the browser opens the stream again.

In the browser, @StreamRequest is JavaScript, TypeScript or Go.
A Go client is an interface method such as Receive(tick Tick);
the page holds the stream for the Go service that keeps the client
in a // @Needs field, and that service receives each message with
// @OnEvent.

JavaScript and TypeScript require a runtime supporting the authored
stream syntax; Node is the default. Other languages still require
their supported interpreter or compiler toolchain.
