# Phase 3 Tac View Evidence

> Historical record: the SSR-island assertions in this phase were superseded
> by ADR 0015 on 2026-08-10. Current Tac qualification requires an exclusively
> client-rendered plan. ADR 0016 removes the experimental Yon view system.

## Status

Phase 3 is complete as a development milestone on 2026-07-26. It is not a
preview or supported Tachyon release. The normative contract and explicit
deferrals are in [`PHASE_3_SPEC.md`](PHASE_3_SPEC.md).

## Delivered Outcome

The current `ty build` command parses bounded Tac templates, lowers View IR v1,
emits client render plans and View Source Map v1, and reuses only verified
route artifacts. Yon handlers are discovered for manifests but never executed
by the build.

Both `<logic>/<loop>` compatibility tags and `<if>/<else>/<for>` aliases are
compiler syntax and never leak into emitted HTML. Failed builds retain the
last complete output.

## Behavioral Evidence

The normal workspace gate has 90 deterministic Rust tests:

- 6 real-binary Phase 1 acceptance tests;
- 5 real-binary Phase 2 handler acceptance tests;
- 7 real-binary Phase 3 view acceptance tests;
- 6 shared real-process JavaScript/Python adversarial tests;
- 5 contract registry and wire-shape tests;
- 7 repository policy tests;
- 48 core compiler, view, handler, server, discovery, and scaffold tests;
- 6 diagnostic contract tests.

The current Phase 3 corpus proves:

- JavaScript and Python Yon handlers are discovered without executing static
  fields or `GET()`, and `yon.html` is rejected;
- condition chains, loops, escaped interpolation, dynamic attributes,
  component properties, slots, and ordinary web components lower to a bounded
  client render plan;
- malformed expressions and controls, component cycles, missing component
  companions, and independent source failures fail with stable diagnostics;
- View IR contains structural expressions but no evaluated values, while source
  maps point generated byte ranges to page and component inputs;
- all component mount policies run after the browser creates the DOM, and
  activating policies copy only their registered companion modules;
- unchanged Tac routes reuse digest-verified artifacts, component changes
  invalidate routes, corrupt state safely misses, `--no-incremental` forces
  compilation, and handler-only routes emit no view artifact.

The repeatable browser gates build with the real Rust binary, serve fixtures,
and drive headless Chromium. They prove initial client rendering, public props,
same-origin modules, component mount scheduling, browser-owned structural
updates, event handling, and a module-free `never` component.

## Explicit Boundary

Phase 3 is deterministic compilation to browser-owned render plans. It does not
add production HTTP dispatch, arbitrary JavaScript expressions, raw HTML, SPA
navigation, streaming, native rendering, WebSurface fallback, stable release
packaging, or OS-level handler sandboxing. Yon remains outside this pipeline.
