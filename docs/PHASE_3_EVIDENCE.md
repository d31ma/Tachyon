# Phase 3 Tac and Yon View Evidence

## Status

Phase 3 is complete as a development milestone on 2026-07-26. It is not a
preview or supported Tachyon release. The normative contract and explicit
deferrals are in [`PHASE_3_SPEC.md`](PHASE_3_SPEC.md).

## Delivered Outcome

The compiled Rust `ty build` command parses bounded Tac/Yon templates, lowers
View IR v1, composes same-level JavaScript and Python Yon class fields plus
`GET()` objects, expands Tac components and slots, contextually escapes output,
emits server-rendered islands and View Source Map v1, and reuses only verified
handler-free route artifacts.

Both `<logic>/<loop>` compatibility tags and `<if>/<else>/<for>` aliases are
compiler syntax and never leak into emitted HTML. Failed builds retain the
last complete output.

## Behavioral Evidence

The normal workspace gate has 90 deterministic Rust tests:

- 6 real-binary Phase 1 acceptance tests;
- 5 real-binary Phase 2 handler acceptance tests;
- 7 real-binary Phase 3 view acceptance tests;
- 6 shared real-process JavaScript/Python adversarial tests;
- 5 contract registry and wire-shape tests;
- 7 repository policy tests;
- 48 core compiler, view, handler, server, discovery, and scaffold tests;
- 6 diagnostic contract tests.

The Phase 3 corpus proves:

- JavaScript and Python static fields and async `GET()` results compose into
  one deterministic route context with sorted manifest export names;
- condition chains, loops, escaped interpolation, dynamic attributes,
  component properties, slots, and ordinary web components render correctly;
- duplicate context keys, malformed expressions and controls, component
  cycles, missing island companions, and independent source failures fail with
  stable diagnostics;
- View IR contains structural expressions but no evaluated values, while source
  maps point generated byte ranges to page and component inputs;
- all island policies retain SSR, `never` emits no module or properties, and
  activating policies copy only their registered companion modules;
- unchanged static routes reuse digest-verified artifacts, component changes
  invalidate routes, corrupt state safely misses, `--no-incremental` forces
  compilation, and handler routes always rerender.

The repeatable `bun run test:rust-browser` gate builds with the real Rust
binary, serves the fixture, and drives headless Chromium. It proves load
activation, public props, same-origin modules, SSR preservation after a thrown
activation, a module-free never island, and one replayed interaction after
successful hydration. The same behavior was independently observed in the
Codex in-app Chromium browser.

## Explicit Boundary

Phase 3 is deterministic build-time web prerendering. It does not add
production HTTP dispatch, arbitrary JavaScript expressions, raw HTML, browser
reactivity, SPA navigation, streaming, native rendering, WebSurface fallback,
stable release packaging, or OS-level handler sandboxing. Those capabilities
remain later phase work.
